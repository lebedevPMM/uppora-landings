# uppora «Диалог» — design brief (жанр-пивот: сайт-мессенджер)

- **Design read:** авторы, живущие в Telegram; регистр — тёплый личный разговор, не презентация.
- **Concept spine:** «САЙТ = ПЕРЕПИСКА». Никакого лендинга: посетитель попадает в чат с выдрой Уппи (маскот-основатель). Уппи печатает, посетитель отвечает кнопками и полями. Донат показывается ЖИВЬЁМ — прилетает сообщением в чат. Страница автора собирается ИЗ диалога и появляется карточкой в переписке. Медиум = сообщение продукта: донат и есть сообщение признания.
- **Delivery tier:** conversational (без скролл-повествования; хореография = очередь сообщений, typing-ритм, автоскролл).
- **Locked palette:** фон чата #0F1210 (тёмный мессенджер) · пузыри Уппи #1C221D · пузыри посетителя #00C147 (ink-текст) · акцент #7FE0A7 · карточки-вложения #F0F5EF. Шрифт Inter,разговорные размеры.
- **Tier-1:** сам жанр. Плюс: живой донат-в-чате (сообщение-карточка с count-up), сборка страницы из ответов, финальная репетиция признания на собранной карточке.
- **Канон:** 7,5% — вся комиссия; без фейкового соц-доказательства (Уппи говорит от первого лица команды); «Ты не просишь — тебя благодарят» = реплика кульминации.
- **CTA:** нет кнопок-CTA вообще — есть разговор, который заканчивается почтой («куда прислать ключи от кабинета?»).
