# Uppora «Авторам» — design brief (Phase 0)

- **Design read:** русскоязычные авторы (Telegram/IG/стримы), которых бесит рекламная монетизация; регистр — тёплое достоинство, «тебя благодарят», ноль жалости.
- **Concept spine:** «страница ведёт себя как продукт»: лендинг сам работает как сбор на uppora — скролл наполняет полоску цели, финал = «цель закрыта», а посетитель в билдере проживает получение первого доната («репетиция признания»). Show, don't tell на каждом уровне.
- **Delivery tier:** cinema-lite (сюжетные механики + микро-моушн C8; без Lenis/GSAP — весь моушн собственный, verified).
- **Locked palette (бренд uppora, фикс. Brand System):** #00C147 primary · #F0F5EF sage-канвас (Wise-ДНК) · #FFFFFF карточки · #262429 ink · #6F6E72 secondary · #DDDFE1 border · #E6F9EE primary-soft · #00752B/#0B4A22 green-ink/deep. Дефенс: единственный акцент = зелёный, поверхность несёт бренд (sage), элевация через контраст поверхностей.
- **Locked type:** Inter — одна семья по весам (бренд-правило); display 900 (Wise-ДНК), body 400, лейблы 600. Серифов нет.
- **Tier-1 техника:** «страница = сбор» (скролл-прогресс как полоска цели + peak-end финал с конфетти) + «репетиция признания» в билдере — интерактивные, управляются действиями посетителя.
- **Section plan:** hero (пример-карточка + live-лента донатов) → боли 3×reframe → как работает 3 шага → билдер (конструктор = CTA, живое превью, magic-link) → бета-функционал (bento, 2 wide с мини-визуалами) → деньги (statement-band 7,5%, монеты) → сцена признания (автоплей) → FAQ → финал (ink polarity-flip, зелёный display) + футер.
- **Asset plan:** рендеры маскота-выдры из бренд-кита (megaphone/peek/coin, стикер-стиль, прозрачный фон) — hero, превью билдера, сцена, финал, компаньон; OG-cover 3:2 собран из кита; favicon — зелёный круг «u».
- **CTA inventory:** header «Собрать страницу» (ink pill на зелёном) · hero primary «Собрать страницу» (green pill, ink text) + secondary «Как это работает» (white outline) · билдер «Сохранить мою страницу» → «Получить ссылку на кабинет» (полноширинные green) · replay сцены (ghost) · финал «Собрать страницу» (green на ink).
- **Копирайт-канон:** «Ты не просишь — тебя благодарят»; красные флаги: комиссия только «7,5% в бете — вся»; никакого фейкового соц-доказательства; RU-типографика с тире (осознанное отступление от zero-dash правила — язык).
