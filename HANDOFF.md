# Uppora — хендофф двух лендингов для переноса (Игорю)

**Дата:** 2026-07-10 · **Живые референсы (поведение = эталон):**
- «Авторам» (продукт-лендинг): https://uppora-avtoram.higgsfield.app
- «Диалог» (сайт-переписка с Уппи): https://uppora-dialog.higgsfield.app

Оба собраны на React 19 (TanStack Start, SSR). Код написан **переносимо**: один route-компонент + один CSS-файл + ассеты, без сторонних библиотек (ноль зависимостей кроме React). Перенос на ваш Next.js = скопировать разметку/стили/эффект почти как есть.

## Структура пакета

```

  src/page.tsx        — вся страница: JSX-секции + useLanding() (вся интерактивность одним useEffect)
  src/landing.css     — фирменный слой (токены бренда + моушн-токены + все секции)
  public/assets/      — рендеры выдры (megaphone/peek/coin + sad/heart), og-cover, favicon
  public/frames/hero/ — 101 webp-кадр фильма для скролл-скраба (f001..f101)
  design-brief.md     — дизайн-контракт (палитра, тип, секции, механики)
dialog/
  src/page.tsx        — чат-движок (say/sticker/attach/ask/input) + сценарий Уппи
  src/dialog.css      — тема мессенджера
  public/assets/      — стикеры Уппи (uppi-sad/uppi-heart + рендеры), видео-аватар uppi-avatar.mp4 (+постер)
  design-brief.md
```

## Перенос на Next.js (app router)

1. `page.tsx` → client-компонент (`"use client"` сверху). Вся браузерная логика уже изолирована в одном `useEffect` с cleanup — SSR-safe.
2. CSS подключить глобально или через CSS-модуль без переименования классов.
3. `public/*` скопировать в ваш `public/` с теми же путями (`/assets/...`, `/frames/hero/...`) — пути захардкожены.
4. Body-класс: эффект вешает `uppora` / `dlg` на `<body>` (тема). Оставить как есть.

## Точки интеграции (обе страницы)

- **Регистрация (magic link, Better Auth):** ищи коммент `ДЛЯ ИГОРЯ` в page.tsx.
  - «Авторам»: submit формы билдера → `buildPayload()` = `{name, about, amounts[], goal{enabled,title,amount}, email}`. Успех показывать ТОЛЬКО после 2xx; при ошибке сети — данные формы не терять.
  - «Диалог»: после ввода почты → `console.log("uppora register:", st)` = тот же payload из диалога.
- **Аналитика (замер конверсии):** builder_start (первый input) / builder_save / builder_email_submit / builder_success.
- **Футер-ссылки** «Авторам»: `href="#"` — заглушки под условия/политику/поддержку.

## Что где реализовано («Авторам»)

- **Hero-скраб:** sticky-пин `#hero-pin` (280vh), скролл = кадр фильма на canvas (`FR = 101`). Кадр 1 рисуется сразу (poster `<img>` под canvas). Мобайл (<861px): без пина, фильм проигрывается один раз при появлении, тап по плашке = реплей. Reduced-motion: статичный последний кадр.
- **«Страница = сбор»:** верхняя полоска + чип «дочитано N%» → «цель закрыта» + конфетти (≤50 частиц, автостоп 1.5s).
- **Билдер:** живое превью, валидации, email-шаг, успех = «репетиция признания» (карточка посетителя получает +100 ₽; узел карточки переносится в success через appendChild и возвращается при «Исправить почту»).
- **Сцена признания:** автоплей по IntersectionObserver + replay; тайпинг-эффект.
- **Компаньон-выдра:** fixed внизу, позы по секциям (peek/coin), прячется там, где выдра уже есть.
- **Частицы/курсор/марки-лента/жест «+100 ₽ ♥»** — всё в том же эффекте, всё за гейтом `prefers-reduced-motion` и `(hover:hover) and (pointer:fine)`.

## Что где реализовано («Диалог»)

- Чат-движок: `say()` (typing-пауза ∝ длине), `sticker()`, `attach()` (вложения; `[data-amt]` = count-up суммы + сердечки + glow), `ask()` (чипы-ответы) и `input()` (инпут в доке) возвращают Promise — сценарий читается сверху вниз как скрипт.
- Живой аватар: `<video autoplay muted loop playsinline>` + постер. Статус в шапке синхронен с действиями («печатает…»/«отправляет стикер…»/«в сети»).
- Вибро: только после первого pointerdown (иначе браузер ругается).
- Реакция-сердце по тапу на пузырь Уппи.

## Грабли, уже пойманные (не наступать заново)

1. `position: sticky` умирает от `overflow-x: hidden` на body — используйте `html { overflow-x: clip }`.
2. Canvas по умолчанию 300×150 — размер выставлять сравнением с `naturalWidth` кадра, а не `if (!canvas.width)`.
3. Reveal-анимации — mount-fired (CSS animation), НЕ opacity:0 + IntersectionObserver (ломает скриншоты/SEO-рендер).
4. `navigator.vibrate` до первого тапа = console error.
5. Кадры скраба: `ffmpeg fps=20, scale=1280` → webp q72 ≈ 2.1MB на 101 кадр — норм; загрузка стримом с fallback на ближайший загруженный кадр.

## Канон копирайта (не менять без Кости)

- Комиссия: **«7,5% в бете — вся комиссия»** (не «0%», не «более 95%»).
- Никакого фейкового соц-доказательства (счётчиков/отзывов) до реальных порогов.
- «Ты не просишь — тебя благодарят» — ядро. ⚠ Кандидат-заголовок с созвона «Больше денег и любви за то, что ты уже делаешь» — решение по hero за Ильёй/Костей (вторник).
- ⚠ VERIFY до публикации: «вся комиссия» (эквайринг включён?), гостевой донат e2e, QR — подтвердить письменно.
